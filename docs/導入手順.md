# 導入手順

## 事前確認

- Windows PowerShell 7 と Git が使える
- 対象プロジェクトが Git リポジトリである
- Orca から Claude と Codex を起動できる
- `git remote -v` の向き先を確認済みである

## 導入

テンプレートをクローンして `Install-OrcaHarness.ps1` を対象プロジェクトへ実行します。既存ファイルは上書きされません。

```powershell
$source = Join-Path $env:TEMP 'orca-ai-dev-harness'
git clone https://github.com/kohei0408/orca-ai-dev-harness.git $source
& "$source\scripts\Install-OrcaHarness.ps1" -TargetPath 'C:\path\to\your-project'
Remove-Item $source -Recurse -Force
```

対象プロジェクトで `AGENTS.md` の TODO を埋め、`request.md`、`plan.md`、`acceptance.md` を作ります。秘密情報や本番トークンはファイルに書きません。

## 1タスクの実行

`<TASK_ID>` は英数字、`.`、`_`、`-` の短い識別子にします。

```powershell
pwsh .\scripts\Orca-Harness.ps1 init -TaskId <TASK_ID> -RequestFile .\request.md
pwsh .\scripts\Orca-Harness.ps1 gate -TaskId <TASK_ID> -Decision approve
```

ここから先は Codex が実装し、別の Claude がレビューします。

```powershell
pwsh .\scripts\Orca-Harness.ps1 review -TaskId <TASK_ID> -Verdict changes_requested -Message '具体的な指摘'
pwsh .\scripts\Orca-Harness.ps1 fix -TaskId <TASK_ID>
```

レビューが通ったら、先に scope、続いて commit と push の順です。

```powershell
pwsh .\scripts\Orca-Harness.ps1 review -TaskId <TASK_ID> -Verdict approved
pwsh .\scripts\Orca-Harness.ps1 scope -TaskId <TASK_ID>
pwsh .\scripts\Orca-Harness.ps1 safe-commit -TaskId <TASK_ID> -Message 'feat: complete task'
pwsh .\scripts\Orca-Harness.ps1 safe-push -TaskId <TASK_ID>
pwsh .\scripts\Orca-Harness.ps1 deploy-check -TaskId <TASK_ID>
```

## よくある停止

| 表示 | 意味 | 対処 |
|---|---|---|
| `Plan hash changed` | init 後に plan が変更された | 人間が plan を再確認し、不要なら元に戻して再実行。内容変更なら新しい TaskId で init |
| `Maximum of 2 fixes reached` | 自動修正の上限 | Human Gate で手動判断。3回目を自動実行しない |
| `Out-of-scope` | 予定外または秘密ファイルが変更された | `out-of-scope.txt` を確認し、変更を戻すか plan を人間が更新 |
| `Push guard` | レビューかゲートが未承認 | `status` で状態を確認し、承認手順に戻る |

## アンインストール

このハーネスが所有する `.orca/`、`scripts/Orca-Harness.ps1`、`.orca-handoff/` を確認してから、人間が削除します。自動削除コマンドは提供していません。
